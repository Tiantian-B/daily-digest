## 📰 今日AI观点

### Simon Willison 博客

**1. Kimi K3 发布：2.8T 参数的中国开源模型**
- Moonshot AI 发布 Kimi K3（2.8T 参数），承诺 7月27日 开源权重。定价 $3/$15 per M tokens，是中国AI实验室至今最贵的模型。
- Simon 用他的经典"pelican骑自行车"基准测试后指出：**"The biggest limitation of the pelican is that it doesn't touch at all on the thing that matters most for today's model: agentic tool calling and the ability to operate tools reliably as conversations grow in length."** — 他明确指出，当前评估模型好坏的核心指标不是生成能力，而是**agentic tool calling 和长对话中稳定操作工具的能力**。
- K3 目前只有"max"一个推理级别，简单任务也消耗大量 reasoning tokens（一个 SVG 用了 13,241 个 reasoning tokens），成本偏高。

**2. GPT-5.6 系列：Luna / Terra / Sol**
- OpenAI 发布三档模型，Sol 在 Agents' Last Exam 上以 53.6 分超越 Claude Fable 5（高出 13.1 分）。
- 关键新 API 能力：**Programmatic Tool Calling**（模型可编写 JS 来编排工具调用）、**Multi-agent**（模型可自动 spawn 子 agent 做并行工作）、**Prompt cache breakpoints**。
- Simon 的实际体验：Sol "definitely very competent, though so far it hasn't struck me as better than Fable at the kind of complex coding tasks."

### Lilian Weng (OpenAI) 博客

**1. "Harness Engineering for Self-Improvement"（2026-07-04）**
- 探讨递归自我改进（Recursive Self-Improvement）—— 现代 AI 中，模型不是自己改写权重，而是**改进训练管线 + 部署系统，从而产生性能更好的后继模型**。前沿实验室的研究速度已被显著加速。

**2. "Scaling Laws, Carefully"（2026-06-24）**
- 对 scaling laws 的深度审视。Lilian 的风格一贯是用最严谨的数学推导说明核心观点，而不是泛泛而谈。这篇值得作为理解 scaling laws 的"教材级"读物。

**3. "Why We Think"（2025-05-01）**
- 关于 AI 推理机制的深度分析（40分钟阅读时长）。Lilian 的文章特点是：先讲清问题定义，再系统性地梳理各种方法，最后给出自己的判断。

### arXiv 论文速递

1. **"When Words Are Safe But Actions Kill"** — 研究 LLM 作为 embodied agent 规划器时的安全问题：语言上看起来安全的指令，在物理世界执行时可能造成危险。AI 安全最前沿方向。
2. **"Can We Trust Item Response Theory for AI Evaluation?"** — 对 AI 基准测试中 IRT 方法的可靠性提出质疑，AI 评估方法论的最新讨论。
3. **"MM-IssueLoc"** — 多模态仓库级 Issue 定位基准测试（含截图、UI 状态等视觉证据），对 AI coding 能力评估有参考价值。

## 🚀 值得关注的项目

### 1. xai-org/grok-build ⭐18.7K
xAI 的 coding agent harness + TUI。Rust 实现，全屏鼠标交互，可扩展。**为什么值得看：** 这是 Elon 的 xAI 开源的最新产品，对标 Claude Code / Codex CLI。看大厂如何设计 coding agent 的交互模式，对 PM 理解"AI 辅助编程"的产品形态有直接参考价值。

### 2. elder-plinius/T3MP3ST ⭐4.9K
多智能体红队测试平台。**为什么值得看：** AI Agent 能力越强，安全红队的价值越大。这个项目展示了如何用 Agent 测试 Agent 的安全性——"以子之矛攻子之盾"的思路正在成为行业标配。

开源 AI 科研工作台。**为什么值得看：** AI for Science 是个明确的趋势。这个项目把 LLM 能力封装到科研工作流中，对 PM 理解"AI 如何改变知识工作"是个很好的样本。

### 4. MDX-Tom/gpt-5.6-instruct ⭐2.0K
